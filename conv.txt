## **ÉTAPE 2 : Charger des documents dans ChromaDB**

### 🎯 Objectif
Charger un PDF, le découper en petits morceaux (chunks), et les stocker dans une base vecteurs ChromaDB. Puis chercher les morceaux pertinents.

### 📋 À faire :

**1) Installe les dépendances :**
```bash
pip install chromadb langchain langchain-community pypdf
```

**2) Crée un document de test (`test_doc.txt`) :**
```
Python est un langage de programmation créé par Guido van Rossum en 1991.
Python est très populaire pour la data science et l'IA.
FastAPI est un framework web moderne et rapide pour Python.
Les bases de données vectorielles stockent des embeddings.
ChromaDB est une base vecteurs facile à utiliser et locale.
```

**3) Mets à jour `main.py` :**
```python
from fastapi import FastAPI
import chromadb
from langchain.text_splitter import RecursiveCharacterTextSplitter

app = FastAPI()

# Initialise ChromaDB (stockage local dans un dossier)
client = chromadb.PersistentClient(path="./chroma_data")
collection = client.get_or_create_collection(name="documents")

# Fonction pour charger et stocker les documents
def load_documents():
    # Lis le fichier
    with open("test_doc.txt", "r", encoding="utf-8") as f:
        text = f.read()
    
    # Découpe le texte en chunks (max 100 caractères, overlap de 20)
    splitter = RecursiveCharacterTextSplitter(
        chunk_size=100,
        chunk_overlap=20
    )
    chunks = splitter.split_text(text)
    
    # Stocke dans ChromaDB
    for i, chunk in enumerate(chunks):
        collection.add(
            ids=[f"doc_{i}"],
            documents=[chunk],
            metadatas=[{"source": "test_doc.txt"}]
        )
    
    print(f"✅ {len(chunks)} chunks chargés dans ChromaDB")

# Fonction pour rechercher
def search_documents(query: str):
    results = collection.query(
        query_texts=[query],
        n_results=3  # Retourne les 3 meilleurs résultats
    )
    return results

@app.get("/")
def read_root():
    return {"message": "RAG Agent prêt!"}

@app.post("/load")
def load():
    load_documents()
    return {"status": "Documents chargés"}

@app.get("/search")
def search(query: str):
    results = search_documents(query)
    return {
        "query": query,
        "results": results["documents"][0] if results["documents"] else []
    }
```

**4) Lance le serveur :**
```bash
uvicorn main:app --reload
```

**5) Teste :**

D'abord, charge les documents :
```bash
curl -X POST http://127.0.0.1:8000/load
```

Puis cherche :
```bash
curl "http://127.0.0.1:8000/search?query=Python et IA"
```

Tu devrais voir les chunks pertinents retournés ! 

---

### 🧠 Ce qui se passe :
- **Splitter** = découpe le texte en petits morceaux (chunks)
- **ChromaDB** = stocke les chunks + calcule automatiquement des embeddings (représentations numériques)
- **Query** = cherche les chunks les plus proches sémantiquement de ta question

### ⚠️ Note importante :
ChromaDB calcule les embeddings **automatiquement** avec un modèle par défaut. C'est magique pour débuter !
